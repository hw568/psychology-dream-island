1. 感知覺醒島

探討感覺（Sensation）與知覺（Perception）的奧秘，理解大腦如何將物理刺激轉譯為心理現實。

學習目標：區分感覺與知覺的差異，解釋感覺適應、絕對閾限與知覺組織原則（完形心理學）。

感覺與知覺的轉化

感覺是感覺受器接收外界物理能量並轉為神經衝動的歷程；知覺則是大腦組織、詮釋這些感覺訊息以賦予意義的心理歷程。大腦並非單純錄影，而是主動建構我們眼前的世界。

完形組織原則與知覺恆常性

完形心理學（Gestalt）提出「整體大於部分的總和」。透過接近性、相似性、閉合性與連續性法則，大腦自動整合視覺片段。知覺恆常性（大小、形狀、顏色）則讓我們在環境刺激改變時仍保持穩定認知。

知覺恆常性反思

請觀察日常生活中「硬幣傾斜時視網膜上是橢圓形，但大腦仍知覺它是圓形」的經驗，記錄知覺恆常性如何幫助我們維持穩定的空間認知。

心理學經典實驗：視覺懸崖 Gibson & Walk (1960) 探討嬰兒深度知覺的經典研究。

自編練習題

感覺（Sensation）與知覺（Perception）的核心差異為何？
  1. 感覺是接收物理刺激，知覺是大腦組織詮釋訊息
  2. 知覺只發生在眼球，感覺發生在大腦皮質
  3. 兩者毫無差異，皆為反射行為
  4. 感覺由意識控制，知覺純屬潛意識反應

正確答案：感覺是接收物理刺激，知覺是大腦組織詮釋訊息
感覺著重於受器接收外界物理能量轉為神經衝動；知覺則是大腦對這些訊號進行選擇、整合與詮釋的認知歷程。

長時間處在有氣味的房間後逐漸聞不到該氣味，此現象在心理學中稱為？
  1. 感覺適應（Sensory Adaptation）
  2. 知覺恆常性
  3. 完形組織法則
  4. 條件反射消退

正確答案：感覺適應（Sensory Adaptation）
感覺適應是指感官受器受到持續且不變的刺激時，感受性逐漸下降的生理與心理調適機制。

完形心理學（Gestalt Psychology）所強調的核心觀念是什麼？
  1. 整體大於部分的總和
  2. 人類行為完全由潛意識驅力主導
  3. 刺激與反應之間只有機械式連結
  4. 知覺是由獨立元素被動相加而成

正確答案：整體大於部分的總和
完形心理學家指出，個體在知覺時會主動將零散刺激組織成有意義的整體結構，而非單純的元素拼貼。

當朋友漸漸走遠，他在你視網膜上的影像雖然縮小，你卻不會認為他身材變矮，這是因為？
  1. 大小恆常性（Size Constancy）
  2. 雙眼視差
  3. 感覺適應
  4. 錯覺誘發

正確答案：大小恆常性（Size Constancy）
大小恆常性是指在視網膜成像大小隨距離改變時，大腦能結合距離線索，依舊知覺物體保持原本大小的特性。

2. 記憶之宮島

解密經典制約、操作制約與人類多重記憶系統，掌握記憶編碼與抗遺忘策略。

學習目標：分析短期工作記憶限制，運用艾賓浩斯遺忘曲線與間隔重複法提升記憶鞏固效率。

制約學習：從巴甫洛夫到斯金納

經典制約（古典制約）探討非條件刺激與條件刺激的聯結（如狗聽到鐘聲流口水）；操作制約則聚焦於行為後的強化（正強化、負強化）與懲罰如何塑造個體主動行為。

多儲存記憶模型與遺忘曲線

感官記憶、短期記憶（工作記憶，容量約7±2組塊）與長期記憶（陳述性與非陳述性）構成記憶的三重架構。艾賓浩斯發現遺忘在剛學完後最快，間隔複習（Spaced Repetition）是鞏固長期記憶最有效的途徑。

記憶宮殿實踐法

選擇熟悉的一條回家路徑或房間角落，將需要記憶的5個心理學概念形象化為誇張物件放置在定點，練習空間定位回想。

艾賓浩斯遺忘曲線研究 人類記憶保持率隨時間變化的科學記錄。

自編練習題

巴甫洛夫古典制約實驗中，狗聽見鈴聲分泌唾液的現象屬於？
  1. 條件反應（Conditioned Response）
  2. 無條件反應
  3. 操作性行為
  4. 自發性知覺

正確答案：條件反應（Conditioned Response）
唾液分泌原本是對食物（無條件刺激）的非條件反應，經由與鈴聲配對後，對鈴聲所產生的反應即稱為條件反應。

心理學家喬治·米勒（George Miller）提出的短期工作記憶容量魔術數字約為多少？
  1. 7 ± 2 個組塊（Chunks）
  2. 15 ± 3 個組塊
  3. 3 ± 1 個組塊
  4. 無限制容量

正確答案：7 ± 2 個組塊（Chunks）
米勒在 1956 年提出人類短期記憶一般可同時維持 5 到 9 個（7±2）有意義的組塊（chunks）。

根據艾賓浩斯（Ebbinghaus）遺忘曲線，對抗遺忘最有效的複習策略是？
  1. 在記憶流失初期進行間隔重複（Spaced Repetition）
  2. 在考前前一晚一次性死記硬背
  3. 只閱讀一次不再重複
  4. 依賴潛意識在睡眠中自動記憶

正確答案：在記憶流失初期進行間隔重複（Spaced Repetition）
遺忘曲線顯示遺忘在學習完成後幾小時至數天內速度最快，因此在各個間隔點主動提取複習可大幅鞏固神經突觸連結。

學會騎自行車、游泳或盲打鍵盤後多年不忘，這屬於長期記憶中的哪一種類型？
  1. 程序性記憶（Procedural Memory）
  2. 語意記憶（Semantic Memory）
  3. 情節記憶（Episodic Memory）
  4. 短期感官記憶

正確答案：程序性記憶（Procedural Memory）
程序性記憶屬於非陳述性（隱性）記憶，涉及動作技能與行為序列的自動化執行，難以用語言完整描述但持久不易遺忘。

3. 理性思維島

探究人類思考、捷思法（Heuristics）與常見認知偏誤，鍛鍊批判性思維。

學習目標：識別系統一（快思）與系統二（慢想）的運作機制，學會辨識定錨效應與確認偏誤。

雙系統思維模型

康納曼（Daniel Kahneman）提出人類思維由「系統一」（直覺、快速、自動化、消耗能量少）與「系統二」（深思、緩慢、邏輯運算、需高度專注）共同主導。捷思法是系統一為節省心力採取的思考捷徑。

常見認知偏誤與防範

可得性捷思使人過度高估容易聯想事件的發生率；定錨效應讓人過度受初始數字影響；確認偏誤則讓人只尋找支持既有觀點的證據。保持對自身認知盲點的警覺是理性思考的起點。

偏誤檢核日記

記錄今天一次衝動決定或觀點爭論，分析是否有「確認偏誤」或「可得性偏誤」介入。

快思慢想與行為經濟學導讀 諾貝爾經濟學獎得主康納曼經典代表作。

自編練習題

康納曼（Daniel Kahneman）提出的「系統一」思考具有何種運作特徵？
  1. 快速、自動化且高度仰賴直覺經驗
  2. 緩慢、費力且遵循嚴密形式邏輯
  3. 需要高度注意力與主動意志力
  4. 專門負責複雜數學運算

正確答案：快速、自動化且高度仰賴直覺經驗
系統一宛如大腦的自動駕駛模式，能快速做出日常反應與直覺推斷，但容易受啟發式捷思的盲點誤導。

在購物討價還價時，最初標示的原價往往會深刻左右消費者對特價的評價，此心理現象稱為？
  1. 定錨效應（Anchoring Effect）
  2. 後見之明偏誤
  3. 光環效應
  4. 稟賦效應

正確答案：定錨效應（Anchoring Effect）
定錨效應是指人在決策過程中，過度仰賴接收到的第一筆資訊（錨點），即使該數字可能不客觀甚至隨機。

人們傾向主動搜尋、偏愛與牢記符合自身既有立場的資訊，忽視相反事實，這稱為？
  1. 確認偏誤（Confirmation Bias）
  2. 代表性捷思
  3. 基本歸因謬誤
  4. 自我設限

正確答案：確認偏誤（Confirmation Bias）
確認偏誤會讓大腦主動濾除不同觀點的資訊，導致立場極化與回音室效應，是批判思維最大的敵人。

剛在新聞上看見飛機失事報導，隨後幾天便過度高估搭乘飛機的危險性，這是受到哪種心理機制的影響？
  1. 可得性捷思（Availability Heuristic）
  2. 沉沒成本效應
  3. 賭徒謬誤
  4. 過度自信偏誤

正確答案：可得性捷思（Availability Heuristic）
可得性捷思使人傾向依賴記憶中最容易被提取或鮮明的實例（如近期震撼新聞）來評估事件發生的客觀機率。

4. 動機與情緒島

探索人類行為背後的內在驅力、馬斯洛需求層次理論與情緒生理調節。

學習目標：辨析內在動機與外在動機，理解情緒的詹姆斯-蘭格理論與沙赫特認知標籤理論。

馬斯洛需求階層與自我實現

馬斯洛將人類需求由基底向頂層排列：生理需求、安全需求、愛與歸屬、尊重需求，直到最高階的「自我實現需求」。當較低層次匱乏需求獲得滿足後，成長性需求便會成為主要動機。

情緒的本質與身心互動

情緒包含生理喚醒、主觀體驗與外顯行為。沙赫特-辛格二因素理論指出，情緒是「生理喚醒」加上「認知評價」的產物。學會情緒覺察與正向重估（Cognitive Reappraisal）能有效化解焦慮。

動機源流盤點

列出你目前投入最多時間的一項活動，評估它是來自「內在動機」（純粹興趣、自我成長）還是「外在動機」（報酬、社會期待）。

馬斯洛需求層次論 人本主義心理學核心理論架構。

自編練習題

根據馬斯洛（Maslow）的需求層次理論，金字塔的最頂層目標為何？
  1. 自我實現需求（Self-Actualization）
  2. 自尊與地位需求
  3. 愛與歸屬需求
  4. 安全與穩定需求

正確答案：自我實現需求（Self-Actualization）
自我實現是充分發揮個人潛能、實現理想自我的最高成長性需求，位於馬斯洛需求階層頂端。

一個孩子因為純粹享受繪畫的樂趣而廢寢忘食作畫，這展現了何種動機型態？
  1. 內在動機（Intrinsic Motivation）
  2. 外在動機（Extrinsic Motivation）
  3. 生理匱乏動機
  4. 替代性增強

正確答案：內在動機（Intrinsic Motivation）
內在動機源於個體對活動本身的興趣、勝任感或探索慾望，活動本身即是最大的獎賞。

沙赫特-辛格（Schachter-Singer）的情緒二因素理論主張，情緒體驗源於哪兩者的結合？
  1. 生理喚醒（Arousal）與環境認知標籤（Cognitive Label）
  2. 潛意識壓抑與本能衝動
  3. 面部表情肌肉與腦幹電位
  4. 遺傳基因與童年創傷

正確答案：生理喚醒（Arousal）與環境認知標籤（Cognitive Label）
該理論指出，當個體感受到生理喚醒時，會主動觀察環境線索並進行認知詮釋，從而定義自己正處於憤怒、恐懼或歡欣等特定情緒狀態。

當遭遇演講緊張時，主動將「心跳加速」重新詮釋為「身體正充滿能量迎接挑戰」，此調節策略稱為？
  1. 認知重估（Cognitive Reappraisal）
  2. 情緒壓抑
  3. 逃避反應
  4. 習得無助

正確答案：認知重估（Cognitive Reappraisal）
認知重估透過改變對引發情緒刺激的認知評價，主動轉化情緒反應的強度或性質，是一種成熟健康的適應策略。

5. 人格演繹島

探究個體獨特且持續的行為模式，解析大五人格特質（OCEAN）與艾瑞克森心理社會發展。

學習目標：理解大五人格特質（開放性、嚴謹性、外向性、親和性、神經質）並認識自尊與自我效能。

大五人格模型（Big Five）

現代特質論公認的五大維度為 OCEAN：開放性（Openness）、嚴謹性（Conscientiousness）、外向性（Extraversion）、親和性（Agreeableness）與神經質／情緒穩定性（Neuroticism）。每個人在各維度上都有連續性的落點。

自我效能與終身發展

班杜拉（Bandura）提出「自我效能感」（Self-efficacy），即個體對自己能否成功完成某項任務的信心信念。艾瑞克森則將人生劃分為八個心理社會階段，每個階段皆有其核心衝突與自我成長課題。

自我特質星盤

以 1 到 5 分為自己的 OCEAN 五個特質維度打分，並舉出一個近期行為佐證你的自我觀察。

大五人格模型科學概覽 實證心理學廣泛採用的人格特質測量模型。

自編練習題

在大五人格特質（Big Five / OCEAN）中，字母「C」代表哪一項特質？
  1. 嚴謹性／盡責性（Conscientiousness）
  2. 同情心（Compassion）
  3. 創造力（Creativity）
  4. 自信度（Confidence）

正確答案：嚴謹性／盡責性（Conscientiousness）
Conscientiousness 代表自律、組織能力、責任感與目標導向，得分高者通常行事縝密、有條不紊。

心理學家班杜拉（Bandura）提出個體對自己能否完成特定任務的信念，稱為？
  1. 自我效能感（Self-Efficacy）
  2. 外在控制信念
  3. 投射作用
  4. 自我防衛機轉

正確答案：自我效能感（Self-Efficacy）
自我效能感是個人相信自己具備組織和執行行動以達成目標的信心程度，直接影響目標選擇與面對挫折時的堅持度。

艾瑞克森（Erikson）的人生八階段發展論中，青少年時期的核心心理社會危機是？
  1. 自我認同 vs 角色混淆（Identity vs Role Confusion）
  2. 信任 vs 不信任
  3. 自主 vs 羞怯懷疑
  4. 親密 vs 孤立

正確答案：自我認同 vs 角色混淆（Identity vs Role Confusion）
青少年階段（約12-18歲）個體正積極整合自我價值、志向與社會角色，建立清晰的自我認同感。

一個人熱愛冒險旅行、對新奇藝術與抽象哲學充滿好奇，通常在大五人格哪一維度得分較高？
  1. 開放性（Openness to Experience）
  2. 神經質
  3. 從眾性
  4. 嚴謹性

正確答案：開放性（Openness to Experience）
經驗開放性反映個人對新觀念、藝術審美、知性探索與非傳統價值觀的接納與追求程度。

6. 社會共振島

解碼人際互動、從眾壓力、旁觀者效應與社會影響力，建立同理心與健康群己關係。

學習目標：解析阿希從眾實驗與米爾格倫服從實驗，說明責任分散效應與破除旁觀者冷漠的策略。

社會影響力：從眾與服從

阿希（Asch）線段實驗展示了個體在團體壓力下即使答案明顯錯誤也會選擇從眾；米爾格倫（Milgram）電擊實驗則警示了人們對權威服從的深刻傾向。了解這些現象能幫助我們保有獨立批判思考。

旁觀者效應與利他行為

當現場旁觀者人數越多，單一個人挺身相助的機率反而降低，此即「責任分散」（Diffusion of responsibility）。若需要幫助，指定具體對象（例如「穿藍色外套的先生請幫忙報警」）能有效打破冷漠。

阿希從眾實驗回顧 社會心理學經典從眾歷程研究。

自編練習題

著名的阿希（Solomon Asch）線段判斷實驗主要揭示了哪種人際心理現象？
  1. 從眾效應（Conformity）
  2. 社會助長
  3. 認知失調
  4. 社會懈怠

正確答案：從眾效應（Conformity）
阿希實驗發現，即使線段長短判斷答案一目了然，當周遭暗樁一致給出錯誤答案時，約有三分之一的受試者會屈從多數壓力給出錯誤答案。

當緊急事故現場的旁觀者人數越多，單一個人主動上前協助的機率反而下降，這種現象主要是因為？
  1. 責任分散（Diffusion of Responsibility）
  2. 社會回饋理論
  3. 群體極化
  4. 從眾促進

正確答案：責任分散（Diffusion of Responsibility）
旁觀者效應中，在場人數增加會稀釋每個人感受到的道德責任感，大家互相觀望導致集體延遲救援行動。

米爾格倫（Stanley Milgram）主持的著名電擊實驗，主要研究人類何種社會心理行為？
  1. 對權威的服從（Obedience to Authority）
  2. 同理心的發展階段
  3. 暴力媒體的模仿效應
  4. 團隊合作的凝聚力

正確答案：對權威的服從（Obedience to Authority）
米爾格倫實驗震撼性地揭示了：在具備合法權威的指示下，極高比例的普通人會願意執行違背個人良心的有害指令。

在人潮擁擠的街頭若突發意外需要求救，根據旁觀者效應研究，最有效的求救方式是？
  1. 指著特定對象並說：「穿黑色外套的先生，請幫我打119」
  2. 對著空中大喊：「有人可以救救我嗎？」
  3. 保持沉默等待好心人主動上前
  4. 泛稱「大家快來幫忙」

正確答案：指著特定對象並說：「穿黑色外套的先生，請幫我打119」
明確指定特定單一對象並賦予具體任務，能立即打破責任分散狀態，將救助責任落實到具體個人身上。
